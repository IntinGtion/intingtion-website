Official website of the IntinGtion brand.

https://intingtion.de

## 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Fully responsive layout
- Performance-optimized images

## 🎯 Purpose

This project serves as:

- Personal brand website
- Web development practice
- Static performance-focused implementation without frameworks

- `/assets` – images and media
- `/css` – styling
- `/js` – JavaScript functionality
